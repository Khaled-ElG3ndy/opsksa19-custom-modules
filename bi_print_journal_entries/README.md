# Print Journal Entries Report in Odoo

Odoo 19 Community module for printing one or several `account.move` records as
a PDF journal-entry report.

## Features

- **Print Journal Entries** is available in the Print menu of both the form and
  list views.
- A visible **Print Entry** smart button is available on the move form.
- Every selected journal entry starts on a separate PDF page.
- Company logo/name, entry metadata, journal items, debit total, and credit
  total are included.
- English LTR and Arabic RTL layouts follow the current Odoo user language.
