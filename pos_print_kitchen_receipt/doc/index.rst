POS Kitchen Receipt | Customised POS Kitchen Receipt | Print POS Kitchen Receipt
================================================================================

This module allows Odoo POS users to print a POS kitchen receipt.

Installation
============

* Copy the ``pos_print_kitchen_receipt`` module to an addons folder.
* Install the module normally like other modules.
* Enable **Print Kitchen Receipt** on the required Point of Sale.
