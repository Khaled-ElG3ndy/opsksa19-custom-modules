# Release Notes

## 19.0.1.0.0

First release for Odoo 19.

* Print the order's customer as a labelled `Client:` line under *Served by*,
  and drop the unlabelled name the core receipt printed lower down so it is not
  shown twice.
* Print a `VAT% / VAT / ExVAT / Total` summary at the foot of the receipt, one
  row per tax.
* Arabic translations for every label, and a receipt that mirrors with the
  interface.
