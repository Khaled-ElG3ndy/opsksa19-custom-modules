Point of Sale · Odoo 19

POS Default Customer

Choose a customer once, per Point of Sale, and every order the cashier opens starts with that customer already selected.

Set once, per shop

The customer lives on the Point of Sale configuration, so two shops on the same database can default to two different customers.

Always reaches the session

A Point of Sale only preloads a slice of the address book. The chosen customer is shipped to the session regardless, so it is never missing when the register opens.

Never in the way

The cashier can still change the customer, or clear it, on any order. Only newly created orders get the default back.

Arabic and English

Every label is translatable and ships translated, and the module adds no direction-specific styling, so it reads correctly in RTL and LTR alike.

How to use it

  1. Open the settings. Go to Point of Sale › Configuration › Settings and pick the Point of Sale you want to configure at the top of the page.
  2. Pick the customer. Under Default Customer in POS Order, set Default Customer to the contact that should be preselected, then save.
  3. Open the register. Every new order now starts with that customer, including the one that follows a completed sale.
Multi-company: a customer belonging to a different company than the Point of Sale is refused, so a shop can never be pointed at a contact its cashiers cannot use.

العميل الافتراضي لنقطة البيع

اختر العميل مرة واحدة لكل نقطة بيع، وسيبدأ كل طلب يفتحه الكاشير بهذا العميل محدَّداً مسبقاً.

إعداد واحد لكل متجر

يُحفظ العميل على تهيئة نقطة البيع نفسها، لذا يمكن لمتجرين على قاعدة البيانات ذاتها أن يعتمد كل منهما عميلاً افتراضياً مختلفاً.

يصل دائماً إلى الجلسة

لا تُحمِّل نقطة البيع سوى جزء من دفتر العناوين، ومع ذلك يُرسَل العميل المختار إلى الجلسة دائماً فلا يغيب عند فتح الصندوق.

لا يعيق العمل

يظل بإمكان الكاشير تغيير العميل أو إزالته من أي طلب، وتعود القيمة الافتراضية في الطلبات الجديدة فقط.

العربية والإنجليزية

جميع النصوص قابلة للترجمة ومترجمة بالفعل، ولا تضيف الوحدة أي تنسيق مرتبط باتجاه معيّن، فتظهر بشكل سليم في الاتجاهين.

طريقة الاستخدام

  1. افتح الإعدادات. من نقطة البيع › التهيئة › الإعدادات، اختر نقطة البيع المطلوبة من أعلى الصفحة.
  2. اختر العميل. ضمن قسم العميل الافتراضي في طلب نقطة البيع، حدِّد العميل الافتراضي ثم احفظ.
  3. افتح الصندوق. سيبدأ كل طلب جديد بهذا العميل، بما في ذلك الطلب الذي يلي إتمام عملية بيع.
تعدد الشركات: يُرفض اختيار عميل تابع لشركة أخرى غير شركة نقطة البيع، حتى لا تُربط نقطة البيع بجهة لا يستطيع الكاشير التعامل معها.
